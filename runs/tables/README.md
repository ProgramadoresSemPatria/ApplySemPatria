# Generated tables

All markdown apply/discovery tables live under `runs/tables/`.

## Layout

| Subfolder | Purpose | Naming |
|-----------|---------|--------|
| **`applications/`** | Main apply checklist (Channel, Status, Post URL, Apply URL) | `applications-YYYY-MM-DD-full.md` |
| **`discovery/`** | Optional archives of discovery-only tables (LinkedIn posts runs, etc.) | `linkedin-posts-{timestamp}.md` |

## Canonical live table (auto-refreshed after apply)

```
~/job-search/runs/tables/applications/applications-$(date +%Y-%m-%d)-full.md
```

Generated by:

```bash
python3 ~/job-search/scripts/generate_applications.py
# or
python3 ~/job-search/scripts/jobsearch.py table
```

**Multi-track:** one table file lists all career tracks (AI Engineer, Android Developer, …).
Each row has a **Track** column. Apply scripts take `--track <id>` so the correct
resume and profile are used. Config lives under `~/job-search/tracks/<id>/`.

Date window persisted in `~/job-search/state/table-window.json`.

## Snapshots

Use an explicit suffix when you want a frozen copy (e.g. Monday window):

```bash
python3 ~/job-search/scripts/generate_applications.py \
  --linkedin-since 2026-08-31 --board-since 2026-08-31 \
  --output ~/job-search/runs/tables/applications/applications-$(date +%Y-%m-%d)-monday.md
```

Only `-full.md` for **today** is auto-updated by `table_refresh.py` after email/DM/URL apply runs.

## Other run artifacts (unchanged)

Board discovery markdown, raw JSON, DM scan, etc. remain in `~/job-search/runs/` (not moved).
