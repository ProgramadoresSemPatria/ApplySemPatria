Estoy ampliando mi búsqueda profesional

Durante los últimos meses, mi búsqueda estuvo principalmente enfocada en posiciones de Desarrollador Backend, especialmente trabajando con Node.js, TypeScript y NestJS.
Es el área en la que construí la mayor parte de mi experiencia profesional, desarrollando REST APIs, microservicios, integraciones entre sistemas, procesamiento asíncrono y soluciones sobre AWS.
Pero también me di cuenta de algo importante: mi experiencia no se limita únicamente a escribir código backend.

A lo largo de mi trayectoria trabajé con integraciones entre ERPs y Marketplaces, APIs, sincronización de datos, procesamiento batch, arquitecturas orientadas a eventos, PostgreSQL, Redis y servicios Cloud, participando en problemas donde entender cómo se conectan y funcionan distintos sistemas es tan importante como desarrollar el software.

Por eso, además de continuar buscando oportunidades como Desarrollador Backend / Backend Developer / Node.js Developer, estoy ampliando mi búsqueda hacia posiciones como:
• Integration Engineer / Integration Developer
• API Integration / Systems Integration
• Applied AI / AI Backend Engineer
• Application Support / Technical Support Engineer
• Technical Consultant / Solutions Engineer

También estoy profundizando mi formación en Inteligencia Artificial aplicada al desarrollo de software, trabajando con LLMs, AI Agents, MCP, RAG y herramientas de desarrollo asistido por IA.

No estoy buscando alejarme del desarrollo de software.
Estoy buscando ampliar el campo en el que puedo aplicar la experiencia que ya construí, mientras continúo aprendiendo y desarrollándome profesionalmente.

Qué tipo de oportunidad estoy buscando?
Un equipo donde pueda aportar experiencia en:
Node.js · TypeScript · NestJS · REST APIs · Microservices · System Integration · AWS · PostgreSQL · Redis · Docker · CI/CD · Event-Driven Architecture · AI-assisted Development

Estoy abierto tanto a oportunidades remotas en LATAM como internacionales, y también a posiciones que representen un desafío nuevo y requieran fortalecer alguna tecnología específica.

Si conocés una búsqueda donde mi perfil pueda encajar, o trabajás en un equipo que esté buscando perfiles con este tipo de experiencia, me encantaría conectar y conversar.

Agradezco muchísimo cualquier recomendación, referencia o contacto que pueda ayudarme a encontrar el próximo desafío.
