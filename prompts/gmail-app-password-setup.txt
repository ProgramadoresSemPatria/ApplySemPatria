  Gmail — app password (recommended)
================================================================================

jobsearch sends application emails from YOUR Gmail address using an
「App password」 (not your normal Gmail password). You only do this once.

Prerequisites
  • A personal Gmail address (Google Workspace may need admin approval).
  • 2-Step Verification turned ON for that Google account.

--------------------------------------------------------------------------------
Step 1 — Turn on 2-Step Verification (skip if already on)
--------------------------------------------------------------------------------

  1. Open: https://myaccount.google.com/signinoptions/two-step-verification
  2. Follow Google’s prompts to enable 2-Step Verification.

--------------------------------------------------------------------------------
Step 2 — Create an app password
--------------------------------------------------------------------------------

  1. Open: https://myaccount.google.com/apppasswords
     (If the link fails: Google Account → Security → 2-Step Verification
      → scroll to 「App passwords」.)

  2. Sign in if asked.

  3. Create a password:
       App name: jobsearch  (any label is fine)
       Click 「Create」

  4. Google shows a 16-character password (often in groups of 4).
     Copy it — you will paste it in the terminal next (input is hidden).

--------------------------------------------------------------------------------
Step 3 — Paste here in the terminal
--------------------------------------------------------------------------------

  • Stored locally only:  secrets/gmail-app-password
  • File permissions 600, never committed to git.

Troubleshooting
  • 「App passwords」 missing → enable 2-Step Verification first (Step 1).
  • Wrong password → create a new app password and paste again:
      jobsearch configure gmail --track YOUR_TRACK

To disable email apply later:
  jobsearch configure gmail --track YOUR_TRACK --disable
