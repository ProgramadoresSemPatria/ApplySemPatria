================================================================================
  Gmail setup — send job applications by email
================================================================================

Use a Google App Password so jobsearch can send application emails on your
behalf (SMTP). You need 2-Step Verification enabled on your Google account.

Steps:

  1. Open https://myaccount.google.com/apppasswords
     (Google Account → Security → 2-Step Verification → App passwords)

  2. Create an app password:
     - App name: "jobsearch" (or anything you like)
     - Copy the 16-character password (spaces optional)

  3. Paste it when prompted below. It is saved locally at:
       secrets/gmail-app-password
     (gitignored, file mode 600 — never committed)

Alternative — Gmail OAuth (advanced):
  See playbooks/gmail-email-apply-setup.md and run:
    jobsearch login gmail --track YOUR_TRACK

To turn Gmail off later:
    jobsearch configure gmail --track YOUR_TRACK --disable

To change manual vs automatic sending:
    jobsearch configure gmail --track YOUR_TRACK
