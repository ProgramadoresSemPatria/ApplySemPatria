# Himalayas

- **URL:** `https://himalayas.app/jobs/api?limit=50&cursor=...`
- **Method:** JSON API with cursor pagination
- **Fields:** `title`, `companyName`, `minSalary`, `maxSalary`, `currency`, `locationRestrictions`, `pubDate`, `applicationLink`
- **Filter:** Title/category keywords client-side; `pubDate` for recency
- **Apply channel:** `external_url`
