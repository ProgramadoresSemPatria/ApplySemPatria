# OpenToWorkRemote

- **URL:** `https://opentoworkremote-api.herokuapp.com/jobs?title=ai+engineer&page=N`
- **Method:** JSON API (discovered from Next.js bundle)
- **Fields:** `title`, `company`, `url`, `location`, `salaryMin`, `salaryMax`, `publicationDate`
- **Pagination:** `pagesInfo.totalpages`
- **Apply channel:** `external_url` (often redirects to source board)
