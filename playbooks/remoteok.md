# RemoteOK

- **URL:** `https://remoteok.com/api?tag=ai` (also `machine-learning`, `llm`)
- **Method:** JSON API, no browser
- **Fields:** `position`, `company`, `salary_min`, `salary_max`, `epoch`, `url`, `location`, `tags`
- **Filter:** Title keywords + tag list from config
- **Apply channel:** `external_url` via `url` or `apply_url`
